# Phonebook

Домашнее задание Нетологии по теме «Regular expressions».

## Возможности программы

- Нормализация фамилий, имён и отчеств.
- Приведение телефонных номеров к единому формату.
- Объединение дублирующихся контактов.
- Сохранение результата в CSV-файл.

## Запуск

1. Скачать исходный файл [phonebook_raw.csv](https://raw.githubusercontent.com/netology-code/py-homeworks-advanced/master/5.Regexp/phonebook_raw.csv).
2. Поместить файл в корневую папку проекта.
3. Выполнить команду `python main.py`.

Результат сохраняется в файле `phonebook.csv`.

Программа использует только стандартную библиотеку Python. Установка дополнительных зависимостей не требуется.
